# 🌸 Lab_2 — Timsort

### 📌 Описание

Вторая лабораторная работа посвящена реализации гибридного алгоритма
сортировки **Timsort**.

В реализации представлены основные элементы алгоритма:

- 🔹 сортировка вставками;
- 🔹 поиск последовательностей `run`;
- 🔹 вычисление `minrun`;
- 🔹 слияние последовательностей;
- 🔹 режим **galloping**;
- 🔹 объединение отсортированных подмассивов.

### 🧠 Основная идея

Массив разбивается на уже частично отсортированные последовательности
`run`.

Небольшие последовательности обрабатываются сортировкой вставками,
после чего объединяются при помощи алгоритма слияния.

# 🌿 Lab_3 — Деревья

### 📌 Описание

Третья лабораторная работа посвящена бинарным деревьям.

Реализованы:

- 🌱 обычное двоичное дерево;
- 🌳 AVL-дерево;
- ➕ вставка;
- ❌ удаление;
- 🔎 поиск;
- 🔄 обход в ширину;
- 🔄 обход в глубину;
- ⚙️ итеративный вариант обходов.

### 🧩 Скобочная запись

Предусмотрено построение дерева из скобочной записи.

Пример:

`(8 (9 (5)) (1))`

Где:

- `8` — корень;
- `9` — левый сын `8`;
- `5` — левый сын `9`;
- `1` — правый сын `8`.

### ⚖️ AVL-дерево

AVL-дерево автоматически поддерживает баланс после операций
вставки и удаления при помощи поворотов.
